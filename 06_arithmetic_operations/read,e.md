# NumPy Arithmetic Operations

NumPy allows us to perform arithmetic operations efficiently on entire arrays without writing explicit loops.

These operations are generally called **vectorized operations**.

## Topics Covered

1. Scalar Operations
2. Array vs Array Arithmetic
3. Comparison Operators
4. Matrix Addition and Subtraction
5. Element-wise Multiplication
6. NumPy Arithmetic Functions
7. Real-world Example

## 1. Scalar Operations

A scalar value can be applied to every element of a NumPy array.

```python
arr + 10
arr - 10
arr * 10
arr / 10
arr ** 2
